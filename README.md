# E-Commerce Sales Data Analysis

## Business Question
This project aims to analyze e-commerce sales performance, customer behavior, and the impact of advertising on sales.

---

## Data Wrangling
The data cleaning process includes:
- Checking data types
- Checking missing values
- Removing null data in `Total_Sales`
- Converting date columns
- Removing invalid data

---

## Insights

### Sales Trend
Monthly sales show fluctuating trends over time.

### Correlation Analysis
Advertising budget has a positive relationship with total sales.

### Underperformer Products
Some high-price products have low sales quantity.

### Category Efficiency
Electronics is the most efficient category, while Gadget has the lowest efficiency.

### RFM Analysis
Several customers show high loyalty and purchasing activity.

---

## Recommendation
- Improve marketing strategies for efficient categories.
- Reevaluate pricing for underperforming products.
- Provide promotions for loyal customers.
- Optimize advertising strategies to increase sales.
